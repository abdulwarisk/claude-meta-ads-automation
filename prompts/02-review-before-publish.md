# Prompt 2: review before you publish

Ask Claude:
```
List the 4 campaigns you just created with objective, budget, audience (locations, age, interests), placements, ad copy, image and link. Flag anything missing or risky. Do not change anything.
```
Then check in **Ads Manager** yourself:
- [ ] Budget and schedule are right
- [ ] Locations, age and interests are right
- [ ] Placements (Facebook, Instagram, Reels, Stories) look okay
- [ ] Image and video preview correctly in every placement
- [ ] Link opens the right page, and UTM parameters are added if you track them
- [ ] Text has no claims you can't prove
- [ ] Pixel or lead form is set up if the objective needs it

Publish (switch them on) yourself when everything is right.
